# ⏰ MessageBox

![Windows](https://img.shields.io/badge/Windows-10%20~%2011-blue)  
⏰ **エラー作成アプリ** for Windows XP / Vista / 7 / 8 / 8.1 / 10 / 11  
🌱 **メモリ使用量 20〜30MB / CPU数％で動作！**  
📦 シンプル・高速なアプリ 

---

## ✅ 特徴

- ✅ **軽量設計**（メモリ20〜30MB！）
- ⚡ **高速起動＆動作**
- 🖥️ **シンプルUI**
- 🎨 Windows XP～11 まで幅広く対応
